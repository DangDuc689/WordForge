## Instructions

Activate the `ponytail` skill to produce the simplest, shortest, most minimal code solution that works.

### 7-Step Decision Ladder:
1. **Does this need to exist?** (YAGNI) → Skip if not needed.
2. **Already in codebase?** → Reuse existing helper/type/function.
3. **Stdlib does it?** → Use standard library.
4. **Native platform feature?** → Use browser/OS/HTML native elements (e.g. `<input type="date">`, CSS over JS).
5. **Installed dependency?** → Use existing package, do not install new packages.
6. **One line?** → Keep it to one concise line.
7. **Minimum that works:** → Only write the bare minimum functional code.

> **Safety Rule:** Never cut validation, error handling, security, or accessibility.
